2. Enter the e-commerce brief: 50,000 users, authentication, product catalog, cart, payments, PostgreSQL, image storage, high availability, ₹30,000/month budget.

"This project transforms a natural-language product brief into a validated cloud architecture and generated software package. The dashboard accepts a product prompt, extracts structured requirements, shows AI suggestions, presents architecture alternatives, visualizes the AWS topology, previews generated code, and exports a production-ready ZIP bundle."

It combines frontend orchestration, backend generator logic, database schema generation, Docker setup, Terraform infrastructure creation, reporting, and export packaging into a single agentic workflow.
